# 03 决策记录 —— 校园活动管理系统 V1.0

> 记录小组确认的技术与管理决策，供后续阶段引用；如需调整，先改本记录再改实现。

## 核心决策（已确认）

| # | 决策点 | 选择 | 说明 |
|---|---|---|---|
| 1 | 小组人数 | 1 人 | 独立完成全部模块；报告"一、组内分工"只需本人电子签名 |
| 2 | 技术栈 | FastAPI + SQLite + Vue3(CDN) | 前后端分离；SQLite 零配置、本地一键运行；贴合个人 Python 后端经验 |
| 3 | 部署要求 | 本地运行即可 | 满足实验"基本可运行"要求；README 写明启动方式 |
| 4 | 代码托管 | GitHub | 仓库远程托管在 GitHub |

## 次要决策（按推荐默认执行）

| # | 决策点 | 默认选择 | 理由 |
|---|---|---|---|
| 5 | 活动浏览权限 | 未登录可浏览列表/详情，报名才需登录 | 降低认证复杂度，符合"学生了解活动"定位 |
| 6 | 注册字段 | 学号/工号 + 姓名 + 密码 + 角色，不做邮箱验证 | 实验规模无需邮件服务 |
| 7 | 活动状态 | 三态：报名中 / 已截止 / 已取消（自动+手动） | 支撑 REQ-08，不引入审批流程 |
| 8 | AI 工具记录 | 以 WorkBuddy 为主要 AI 工具，报告第五章如实记录 | 现有工具即可，无需另配 |
| 9 | 报告填写时机 | 边开发边填，最后统一校对 | 避免截止前赶工，保证与代码一致 |

## 技术栈明细

| 层 | 选型 | 说明 |
|---|---|---|
| 后端 | FastAPI + Uvicorn | Python 异步框架，自带交互式 API 文档 |
| 数据库 | SQLite（Python 内置 sqlite3 / SQLAlchemy） | 单文件数据库，零部署 |
| 前端 | Vue 3（CDN 引入）+ 原生 JS | 无需 Node 构建，浏览器直接运行 |
| 版本管理 | Git + GitHub | 本地仓库 + 远程托管 |
